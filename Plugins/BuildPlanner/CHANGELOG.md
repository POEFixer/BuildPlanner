# Changelog

## 1.0.1

- Importing a build that is already in your list follows that build instead of adding it a second time.
- A character of another class is no longer pointed to the build's ascendancy or told to refund passives first.
- Equipment: slot marks under the build item card no longer show through it.

## 1.0.0

- First release: a Path of Building build shown in the game.
- Passive tree: the next points in order, refunds, weapon set and attribute hints.
- Equipment: the build's item on every slot you hover, and a mark on each slot.
- Skills: the build's skills with their support gems, in a window and on the Skills panel.
- Imports build links and Path of Building codes; the hints show at once.
- Leveling builds: the stage that fits your level is followed by itself.
- Can write the stage you follow into the game's own Build Planner (experimental).
- Ten languages.
